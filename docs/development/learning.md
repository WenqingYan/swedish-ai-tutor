# Learning Material Requirements

## Per-Sentence Analysis

Every sentence in the daily transcript MUST generate:

| Field | Description | Required |
|-------|-------------|----------|
| Original sentence | Exact Swedish from transcript | ✅ |
| Chinese translation | Natural, contextual translation | ✅ |
| Key grammar | Most important grammatical structure | ✅ |
| Key phrases | Reusable multi-word expressions | ✅ |
| Vocabulary | New or notable words | ✅ |
| Word forms | Complete morphological table | ✅ |
| Example sentences | Additional usage of patterns | ✅ |
| SFI notes | Exam relevance and tips | ✅ |

## Rules

1. **Never omit morphology** — Incomplete word entries are worse than no entries.
2. **Never provide translation without grammar context** — Meaning alone does not build proficiency.
3. **Always identify the pattern** — What makes this sentence reusable for the learner?
4. **Flag SFI-relevant structures** — Constructions frequently tested at C/D level get special attention.
5. **Group related words** — If a verb appears, show its noun/adjective cognates.
